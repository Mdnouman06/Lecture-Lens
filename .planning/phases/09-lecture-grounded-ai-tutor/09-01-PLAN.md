  <name>Task 2: Update FastAPI POST /tutor/ask with contextSegments and error handling</name>
  <files>backend/main.py</files>
  <read_first>backend/main.py</read_first>
  <action>
    Update `backend/main.py`:
    1. Update `TutorQuestionRequest` Pydantic model:
       ```python
       class ContextSegmentItem(BaseModel):
           id: Optional[str] = None
           startSeconds: float
           endSeconds: float
           speaker: Optional[str] = "Speaker"
           text: str

       class TutorQuestionRequest(BaseModel):
           question: str
           lectureId: Optional[str] = None
           courseCode: Optional[str] = "ALL"
           chunks: Optional[List[str]] = None
           contextSegments: Optional[List[ContextSegmentItem]] = None
           scope: Optional[Dict[str, bool]] = None
       ```
    2. In `POST /tutor/ask`:
       - Validate `payload.question.strip()`.
       - Catch `OllamaOfflineError` and raise `HTTPException(status_code=503, detail="Local Ollama daemon is offline or unreachable at http://localhost:11434. Please run 'ollama serve' in your terminal.")`.
       - Catch `OllamaModelNotFoundError` as `exc` and raise `HTTPException(status_code=404, detail=f"Model '{exc.model}' is not installed in local Ollama. Please run 'ollama pull {exc.model}'.")`.
       - Call `answer_tutor_question` with `context_segments=[s.dict() for s in payload.contextSegments]` if provided, or `chunks=payload.chunks`.
       - Return formatted tutor response dictionary.
  </action>
  <acceptance_criteria>
    - `TutorQuestionRequest` accepts structured `contextSegments`
    - `POST /tutor/ask` returns 503 with exact instructions when Ollama is offline
    - Returns 400 when question is empty
  </acceptance_criteria>
</task>
