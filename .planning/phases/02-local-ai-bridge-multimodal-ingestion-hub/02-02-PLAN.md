    - Implement `transcribe_file(file_path: str)`:
      - Runs model.transcribe with `vad_filter=True`
      - Collects segments into list: `[{ "id": f"seg-{i}", "startSeconds": round(seg.start, 2), "endSeconds": round(seg.end, 2), "speaker": "Speaker 1", "text": seg.text.strip() }]`
      - Calculates total audio duration and full combined text
    Wire `POST /ingest/audio` into `backend/main.py`:
      - Streams upload to temporary scratch file
      - Invokes `transcribe_file`
      - Cleans up temporary file in a `finally` block
      - Returns `{ "title": filename, "duration": format_duration(total_secs), "durationSeconds": total_secs, "segments": segments, "fullText": text, "status": "ready" }`
  </action>
  <acceptance_criteria>
    - backend/services/transcription.py imports faster_whisper WhisperModel
    - Audio endpoint parses audio, writes temp file, and cleans up on completion
    - Timestamped segment structure matches client TranscriptSegment interface

  <files>backend/services/youtube.py, backend/main.py</files>
  <read_first>backend/main.py</read_first>
  <action>
    Create `backend/services/youtube.py`:
    - Implement `extract_video_id(url: str) -> str`:
      - Handles `youtube.com/watch?v=ID`, `youtu.be/ID`, `youtube.com/embed/ID`, `youtube.com/shorts/ID`
    - Implement `fetch_youtube_captions(video_id: str)`:
      - Calls `YouTubeTranscriptApi.get_transcript(video_id, languages=['en', 'en-US', 'en-GB'])`
      - Formats captions into `TranscriptSegment` format
      - Catches `TranscriptsDisabled`, `NoTranscriptFound`, and generic errors, returning `{ "success": False, "fallback_required": True, "error": str(e) }`
    Wire `POST /ingest/youtube` and `POST /ingest/manual` into `backend/main.py`:
      - `POST /ingest/youtube`: Accepts `{ url, course_code }` and returns transcript or fallback directive
      - `POST /ingest/manual`: Accepts `{ title, text, course_code }`, splits into clean paragraph segments with estimated timecodes, and returns structured lecture payload
  </action>
  <acceptance_criteria>
    - backend/services/youtube.py extracts YouTube video IDs reliably
    - YouTube endpoint catches disabled captions and signals fallback_required
    - POST /ingest/manual chunks raw text into paragraph segments
  </acceptance_criteria>
