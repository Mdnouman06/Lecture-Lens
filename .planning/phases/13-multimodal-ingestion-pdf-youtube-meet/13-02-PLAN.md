<objective>
Implement the Supabase persistence layer and frontend API bridge for multimodal media ingestion:
1. Update `src/types/lecture.ts` so `Lecture` and `DbLectureRow` include `pageCount?: number;` and full multimodal source types.
2. Update `createUserLecture` in `src/services/lectures.ts`:
   - Persist `page_count` to `public.lectures` from `lecture.pageCount`.
   - For PDF slide decks (`sourceType === 'pdf'`), automatically insert an initial `lecture_notes` row in `public.lecture_notes` containing the structured slide markdown and summary (`INGEST-06`).
   - For YouTube lectures (`sourceType === 'youtube'`), persist all timestamped segments to `public.lecture_transcripts` (`INGEST-07`).
   - Map `page_count` in `mapDbRowToLecture`.
3. Update `uploadPdf`, `fetchYouTube`, and `submitManual` in `src/services/api.ts` to cleanly parse backend payloads and forward all structured metadata (`pageCount`, `slides`, `notesMarkdown`, `segments`) to the app.

Purpose: Guarantee that PDF slide text and slide counts persist to `lectures` and `lecture_notes`, and YouTube caption segments persist to `lecture_transcripts`.
Output: Robust Supabase persistence layer and typed frontend API bridge.
</objective>

            - Create an initial `public.lecture_notes` row for the lecture:
              ```ts
              const initialMarkdown = lecture.notesMarkdown || (
                `# ${createdLectureRow.title}\n\n` +
                `**Source:** PDF Slide Deck (${createdLectureRow.page_count || 1} Slides)\n\n` +
                (lecture.summary ? `> ${lecture.summary}\n\n` : '') +
                (lecture.transcript && lecture.transcript.length > 0
                  ? lecture.transcript.map(t => `### ${t.speaker}\n${t.text}`).join('\n\n')
                  : 'Extracted lecture slides ready for synthesis.')
              );
              ```
            - Insert into `public.lecture_notes` (`lecture_id`, `user_id`, `summary`, `markdown`, `key_concepts`).
