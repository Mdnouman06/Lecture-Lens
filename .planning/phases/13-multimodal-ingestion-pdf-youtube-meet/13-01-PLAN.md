<objective>
Refactor and harden the backend multimodal ingestion endpoints in `backend/main.py` and `backend/services/youtube.py`:
1. Enhance `POST /ingest/pdf` to return structured slide markdown (`notesMarkdown`), slide counts, and clean slide chunks.
2. Enhance `POST /ingest/youtube` to parse various YouTube URL formats, extract timestamped segments, and provide clear fallback signaling (`fallbackRequired: True`) with actionable instructions when captions are disabled.
3. Enhance `POST /ingest/manual` to chunk raw lecture text into structured paragraph segments with realistic estimated speaking timecodes (~150 words per minute).
4. Verify and harden `POST /ingest/audio` support for recorded Google Meet and Zoom files (`.mp4`, `.m4a`, `.webm`).
5. Add automated unit tests in `backend/test_api.py` covering all 4 ingestion endpoints.

Purpose: Guarantee that the backend provides reliable, well-typed multimodal media extraction with resilient fallback contracts before wiring to the database.
Output: Hardened FastAPI ingestion routes and comprehensive passing unit tests.
</objective>

  <action>
    1. In `backend/services/youtube.py`:
       - Ensure `extract_video_id` handles:
         - Standard: `https://www.youtube.com/watch?v=VIDEO_ID`
         - Shortened: `https://youtu.be/VIDEO_ID`
         - Embed: `https://www.youtube.com/embed/VIDEO_ID`
         - Shorts: `https://www.youtube.com/shorts/VIDEO_ID`
         - Bare ID: `VIDEO_ID`
       - Ensure `fetch_youtube_captions` catches `TranscriptsDisabled`, `NoTranscriptFound`, and general exceptions, returning:
         ```python
         {
             "success": False,
             "fallback_required": True,
             "videoId": video_id,
             "error": "Captions are disabled by the video owner for this YouTube lecture.",
             "message": "Automated captions are disabled. Please paste the transcript text in the Manual Notes editor."
         }
         ```
       - On success, format segments with `startSeconds`, `endSeconds`, `speaker: "Speaker"`, `text`, plus `durationSeconds`, `wordCount`, and `fullText`.

    2. In `backend/main.py`:
       - In `POST /ingest/pdf`:
         - Clean each extracted slide page, filter empty pages.
         - Build structured `slides`: `[{"page": idx, "text": cleaned_page}]`.
         - Generate structured markdown representation `notesMarkdown`:
           ```python
           notes_lines = [f"# {clean_title}", f"**Source:** PDF Slide Deck ({total_pages} slides)\n"]
           for s in extracted_slides:
               notes_lines.append(f"## Slide {s['page']}\n{s['text']}\n")
           notes_markdown = "\n".join(notes_lines)
           ```
         - Return `{ id, title, filename, courseCode, pageCount, wordCount, slides, text, notesMarkdown, status: "ready", sourceType: "pdf" }`.
       - In `POST /ingest/youtube`:
         - Validate URL and extract video ID.
         - Call `fetch_youtube_captions`.
         - If `fallback_required`, return status 200 with `{ "fallbackRequired": True, "videoId": video_id, "url": payload.url, "error": msg, "message": "Automated captions are disabled. Please paste the transcript text below." }`.
         - On success, return structured lecture dict with `id`, `title`, `videoId`, `url`, `courseCode`, `duration`, `durationSeconds`, `wordCount`, `segments`, `fullText`, `hasAudio: True`, `status: "ready"`, `sourceType: "youtube"`.
       - In `POST /ingest/manual`:
         - Split text into paragraphs by double newlines (`\n\s*\n`).
         - Estimate duration per paragraph based on ~150 wpm: `max(3.0, round((words / 150.0) * 60.0, 1))`.
         - Return structured dict with `id`, `title`, `courseCode`, `duration`, `durationSeconds`, `wordCount`, `segments`, `fullText`, `status: "ready"`, `sourceType: "transcript"`.
       - In `POST /ingest/audio`:
         - Ensure `.mp4` and `.m4a` (Google Meet and Zoom recording formats) are explicitly recognized and allowed.
  </action>
