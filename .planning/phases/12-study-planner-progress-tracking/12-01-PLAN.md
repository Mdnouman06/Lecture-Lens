  <files>backend/services/planner.py</files>

  <action>
    Refactor `backend/services/planner.py`:
    1. Define default baseline 7-day schedule blocks (Monday Oct 27 to Sunday Nov 02) adhering to Google Stitch screen `1680b7e660454bfab5c78955d8803343` with 5 standard categories: `lecture`, `fsrs`, `deep`, `tutor`, `exam`.
    2. Enhance `generate_study_schedule`:
       - Parameter signature: `(blocks: Optional[List[Dict[str, Any]]] = None, exam_deadlines: Optional[List[Dict[str, Any]]] = None, due_flashcards: Optional[int] = None, week_label: str = "Oct 27 – Nov 02") -> Dict[str, Any]`.
       - If `blocks` is None, initialize with default baseline blocks.
       - Calculate total scheduled prep hours across relevant study categories (`deep`, `fsrs`, `tutor`).
       - Compute `prepHoursNeeded`: default to 14.0h or derived from primary upcoming exam deadline.
       - Calculate `coverageDeficit`: `round(prepHoursScheduled - prepHoursNeeded, 1)` (e.g. `10.7 - 14.0 = -3.3h`). If scheduled >= needed, deficit is `0.0`.
       - Compute `dailyTarget`:
         - Determine today's dayIndex (default to 4 / Friday for demo week or current day).
         - Aggregate scheduled hours, deep study hours, and FSRS hours for today.
         - Compute `percentComplete`: completed hours vs target hours (capped between 0 and 100).
    3. Implement intelligent `find_open_time_slots`:
       - Given existing blocks for a day, scan working hours `[8.0, 20.0]` (08:00 to 20:00).
       - Identify gaps where no existing block is scheduled (considering `startHour` and `durationHours`).
       - Return available slot windows `(start_hour, end_hour)` of at least 0.5h duration.
    4. Enhance `autofill_schedule_deficit`:
       - Parameter signature: `(blocks: Optional[List[Dict[str, Any]]] = None, target_hours: float = 14.0, course_code: str = "NEURO 301", lectures: Optional[List[Dict[str, Any]]] = None, due_flashcards: Optional[int] = None) -> Dict[str, Any]`.
       - Computes current coverage deficit. If deficit >= 0, returns the schedule unmodified.
       - If deficit < 0, calculates required additional hours `abs(deficit)`.
       - Scans days prior to the primary exam (e.g. Wednesday and Thursday for a Friday exam).
       - Identifies conflict-free open slots and schedules:
         - Deep Study block (1.5h - 2.0h) grounded in student's lecture concepts (e.g. "⚡ Auto-Filled: High-Yield NMDA & SNARE Henderson Rubric Drill" or lecture concept title).
         - FSRS Spaced Review block (1.0h) (e.g. "⚡ Auto-Filled: Pre-Exam High-Risk Flashcard Sweep (45 cards)").
         - AI Tutor Drill block (0.5h - 1.0h) (e.g. "⚡ Auto-Filled: Henderson Pitfalls AI Tutor Check").
       - Appends generated blocks with `isAutofilled: True`.
       - Recomputes schedule deficit, ensuring `coverageDeficit` becomes `0.0` and `percentComplete` reflects full readiness.
  </action>
