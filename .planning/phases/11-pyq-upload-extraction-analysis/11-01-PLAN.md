       - Use `pypdf.PdfReader` to extract text page by page.
       - Clean up whitespace and sanitize text.
       - Attempt AI question extraction via `analyze_pyq_exam_paper`.
       - If AI extraction is unavailable or returns empty questions, run `parse_pyq_questions_regex(full_text)` to reliably extract questions via regex patterns (`r"(?:Question|Q\.?)\s*(\d+[A-Za-z]?)\s*[:\.\)]\s*(.*?)"`).
       - Generate unique IDs for all extracted questions (`f"q-{uuid.uuid4().hex[:8]}"`).
       - Calculate statistics: `extractedCount`, `shortAnsCount` (marks <= 5), `longAnsCount` (marks > 5), `ocrFidelityPercent` (ratio of printable words).
    2. Implement `generate_topic_weighting_matrix(questions: List[Dict[str, Any]], course_code: str = "ALL")`:
       - Group questions by `topicTag` or extracted topics.
       - Calculate percentage frequency: `(count / total) * 100`.
       - Assign status labels and categories:
         - `>= 25%`: `critical` ("Critical Priority")
         - `>= 15%`: `mastered` ("High Yield")
         - `>= 10%`: `good` ("Good Standing")
         - `< 10%`: `low` ("Low Yield")
       - Return array of `TopicWeight` objects.
    3. Implement `correlate_question_to_lectures(question_text: str, lectures: List[Dict[str, Any]])`:
       - Calculate token overlap between question problem statement and lecture titles, summaries, and key concepts.
       - Select highest-scoring lecture and estimate relevant timecode.
       - Return correlated lecture object: `{ "title": ..., "lectureId": ..., "timecodeDisplay": ..., "seekSeconds": ... }`.
  </action>
