<task type="auto">
  <name>Task 2: Implement Supabase CRUD methods for PYQ papers and questions</name>
  <files>src/services/lectures.ts</files>
  <read_first>src/services/lectures.ts</read_first>
  <action>
    Update `src/services/lectures.ts`:
    1. Implement `mapDbRowToPyqPaper(row: DbPyqPaperRow, questions: PyqQuestionItem[] = []): PyqPaper`.
    2. Implement `mapDbRowToPyqQuestion(row: DbPyqQuestionRow): PyqQuestionItem`.
    3. Implement `fetchPyqPapers(userId: string, courseCode?: string): Promise<PyqPaper[]>`:
       - Query `supabase.from('pyq_papers').select('*').eq('user_id', userId)`.
       - If `courseCode` provided, filter with `.eq('course_code', courseCode)`.
       - Order by `created_at desc`.
       - For each paper, optionally fetch related questions from `pyq_questions`.
       - Return array of `PyqPaper`. Catch errors gracefully and return empty array.
    4. Implement `savePyqPaperToDb(paper: PyqPaper, userId: string): Promise<PyqPaper>`:
       - Upsert payload into `pyq_papers` table with `user_id: userId`.
       - If questions exist on paper, invoke `savePyqQuestionsToDb(paper.id, paper.questions, userId)`.
       - Return saved `PyqPaper`.
    5. Implement `fetchPyqQuestions(paperId: string): Promise<PyqQuestionItem[]>`:
       - Query `supabase.from('pyq_questions').select('*').eq('paper_id', paperId).order('created_at', { ascending: true })`.
       - Return mapped questions.
    6. Implement `savePyqQuestionsToDb(paperId: string, questions: PyqQuestionItem[], userId: string): Promise<PyqQuestionItem[]>`:
       - Format question rows with `paper_id`, `user_id`, stringified or raw JSON for `rubric_criteria`, `common_pitfall`, and `correlated_lecture`.
       - Upsert into `pyq_questions` table.
    7. Implement `deletePyqPaperFromDb(paperId: string, userId: string): Promise<boolean>`:
       - Delete from `pyq_questions` where `paper_id = paperId`.
       - Delete from `pyq_papers` where `id = paperId` and `user_id = userId`.
  </action>
  <verify>
    Inspect `src/services/lectures.ts` to ensure all CRUD functions are exported and typed.
  </verify>
  <acceptance_criteria>
    - `fetchPyqPapers`, `savePyqPaperToDb`, `fetchPyqQuestions`, and `savePyqQuestionsToDb` are exported.
    - All queries enforce `user_id` isolation.
    - Gracefully handles missing Supabase tables without uncaught promise rejections.
  </acceptance_criteria>
</task>
