<objective>
Implement end-to-end input sanitization, prompt injection guardrails, and an automated security test suite:
1. Create `src/utils/security.ts` to provide client-side input sanitization (`sanitizeHtml`, `sanitizeTextInput`, `escapeHtml`, `sanitizeMarkdown`) preventing Stored XSS in lecture notes, margin comments, search queries, and transcript edits.
2. Create `backend/security.py` to protect local AI inference pipelines from prompt injection, delimiter breakout attacks (e.g. `\"\"\"`, ```` ``` ````, `### SYSTEM:`), and oversized payload resource exhaustion.
3. Integrate `sanitize_prompt_input` into `backend/services/ollama.py` (AI Tutor, Note Synthesis, Flashcard/Quiz generation) and `backend/services/pyq.py`.
4. Create an automated test suite `backend/test_security.py` verifying prompt injection neutralization, XSS neutralization, character limit bounds, and safe media container enforcement.

Purpose: Complete security and data persistence hardening (`SEC-01`, `SEC-02`), ensuring LectureLens is robust against input vulnerabilities and adversarial attacks.
Output: Fortified input pipelines, backend security guardrails, passing test suite, and clean production build.
</objective>

  <action>
    Create `src/utils/security.ts` with:
    1. `escapeHtml(text: string): string`: escapes `&`, `<`, `>`, `"`, `'`.
    2. `sanitizeHtml(html: string): string`: strips `<script>`, `<iframe>`, `<object>`, `<embed>`, `<link>`, `onload=`, `onerror=`, `onclick=`, `javascript:` URIs while preserving safe markdown elements (`<p>`, `<b>`, `<i>`, `<code>`, `<pre>`, `<ul>`, `<li>`, `<h1>`-`<h6>`, `<blockquote>`).
    3. `sanitizeTextInput(input: string, maxLength: number = 500): string`: trims whitespace, removes null bytes, normalizes newlines, and bounds string length.
    4. `sanitizeMarkdown(markdown: string): string`: removes dangerous HTML tags and raw script payloads embedded within user markdown notes.
  </action>

<task type="auto">
  <name>Task 2: Create Backend Security Module & Harden AI Services Against Prompt Injection</name>
  <files>backend/security.py, backend/services/ollama.py, backend/services/pyq.py</files>
  <read_first>backend/services/ollama.py, backend/services/pyq.py</read_first>
  <action>
    1. Create `backend/security.py` with:
       - `sanitize_prompt_input(text: str, max_chars: int = 4000) -> str`:
         - Truncates inputs beyond `max_chars`.
         - Neutralizes jailbreak/prompt override prefixes (e.g. `Ignore all previous instructions`, `SYSTEM PROMPT OVERRIDE:`, `You are now in Developer Mode`).
         - Normalizes invisible unicode and null bytes.
         - Escapes triple-quote delimiters (`"""` -> `\"\"\"`) and triple backticks to prevent escaping prompt enclosure templates.
       - `validate_media_filename(filename: str, allowed_extensions: set) -> tuple[bool, str]`:
         - Prevents directory traversal attacks (`../`, `..\`).
         - Validates extension against whitelist.
       - `check_request_size(content_length: int, max_bytes: int = 100 * 1024 * 1024) -> bool`:
         - Rejects requests exceeding size bounds.
    2. In `backend/services/ollama.py`:
       - Import `sanitize_prompt_input` from `security`.
       - Apply `sanitize_prompt_input` to `question` in `answer_tutor_question`.
       - Apply `sanitize_prompt_input` to transcript/notes inputs in `generate_notes_summary`, `generate_active_recall_flashcards`, and `generate_quiz_assessment`.
    3. In `backend/services/pyq.py`:
       - Apply `sanitize_prompt_input` to extracted question text before sending to LLM extraction.
  </action>
  <verify>
    Run `.\.venv\Scripts\python.exe -m py_compile backend/security.py backend/services/ollama.py backend/services/pyq.py` to confirm syntax validity.
  </verify>
