<task type="auto">
  <name>Task 2: Connect LectureWorkspaceView to Supabase notes and live Ollama synthesis</name>
  <files>src/views/LectureWorkspaceView.tsx</files>
  <read_first>src/views/LectureWorkspaceView.tsx</read_first>
  <action>
    Update `src/views/LectureWorkspaceView.tsx`:
    1. Import `fetchLectureNotes`, `saveLectureNotesToDb` from `../services/lectures`.
    2. Import `useAuth` from `../context/AuthContext` (or retrieve current authenticated user).
    3. State variables:
       - `notes`: `StudyNotes | null` (starts null if not on lecture object)
       - `isSynthesizing`: boolean
       - `synthesisError`: `{ message: string; command?: string } | null`
       - `isSavingNotes`: boolean
    4. Auto-Fetch Effect:
       - On mount or when `lecture.id` changes, call `fetchLectureNotes(lecture.id)`.
       - If notes exist in Supabase, set `notes` in state and update lecture via `onUpdateLecture`.
       - If no notes exist in Supabase and `lecture.transcript` has segments, trigger `triggerSynthesis(false)`.
    5. Implement `triggerSynthesis(force: boolean = false)`:
       - Clear previous error; set `isSynthesizing(true)`.
       - Call `synthesizeNotes(lecture.id, transcriptText, lecture.title, lecture.courseCode)`.
       - On success: set `notes`, update lecture, and if user is logged in, auto-save to Supabase via `saveLectureNotesToDb`.
       - On catch error: parse error message; if message contains "ollama serve" or "ollama pull", parse command for the banner; set `synthesisError`.
       - Finally: set `isSynthesizing(false)`.
    6. Implement `handleSaveNotes(updatedNotes: StudyNotes, marginNotes: string)`:
       - Set `isSavingNotes(true)`.
       - Update local `notes` state.
       - If user is authenticated, call `saveLectureNotesToDb(lecture.id, updatedNotes, user.id, marginNotes)`.
       - Also call `saveLectureNotes(lecture.id, updatedNotes, marginNotes)` for backend sync.
       - Update parent via `onUpdateLecture`.
    7. Render:
       - If `isSynthesizing`, render `.notes-synthesis-skeleton` with "Synthesizing lecture notes with local Qwen3...".
       - If `synthesisError`, render `.notes-error-banner` with error message, copyable command button, and "Retry Synthesis" button.
       - If `notes`, render `SmartNotesWorkspace`.
       - If neither and no transcript, show prompt to upload audio or add transcript.
  </action>
  <acceptance_criteria>
    - `LectureWorkspaceView` fetches existing notes from Supabase before attempting synthesis
    - Synthesis loading skeleton displays during Ollama processing
    - Offline/missing model error renders informative banner with command to fix
    - Student edits save to Supabase `lecture_notes` under user ID
  </acceptance_criteria>
</task>
