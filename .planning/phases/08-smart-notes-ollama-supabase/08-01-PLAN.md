  <name>Task 2: Update FastAPI POST /synthesize/notes with robust error handling</name>
  <files>backend/main.py</files>
  <read_first>backend/main.py</read_first>
  <action>
    Update `backend/main.py`:
    1. Import `generate_notes`, `OllamaOfflineError`, `OllamaModelNotFoundError` from `services.ollama`.
    2. In `POST /synthesize/notes`:
       - If `transcript` is empty or only whitespace, return `HTTPException(status_code=400, detail="Transcript text is required for notes synthesis.")`.
       - Catch `OllamaOfflineError` and raise `HTTPException(status_code=503, detail="Local Ollama daemon is offline. Please start Ollama using 'ollama serve' on localhost:11434.")`.
       - Catch `OllamaModelNotFoundError` as `exc` and raise `HTTPException(status_code=404, detail=f"Ollama model '{exc.model}' is not installed. Please run 'ollama pull {exc.model}'.")`.
       - Catch generic unhandled generation errors and raise `HTTPException(status_code=500, detail=f"Note synthesis failed: {str(e)}")`.
    3. Update the response payload to include `lectureId`, `title`, `courseCode`, `summary`, `markdown`, `keyConcepts`, `examRelevance`, `modelUsed`, and `isSimulated`.
  </action>
  <acceptance_criteria>
    - `POST /synthesize/notes` returns HTTP 400 for empty transcripts
    - `POST /synthesize/notes` returns HTTP 503 when Ollama is unreachable with command prompt
    - `POST /synthesize/notes` returns HTTP 404 when configured model is not pulled in Ollama
    - `POST /synthesize/notes` returns valid 200 payload when Ollama generates notes
  </acceptance_criteria>
</task>
