<task type="auto">
  <name>Task 2: Implement Supabase lecture_notes CRUD operations in src/services/lectures.ts</name>
  <files>src/services/lectures.ts</files>
  <read_first>src/services/lectures.ts</read_first>
  <action>
    Update `src/services/lectures.ts`:
    1. Define `DbLectureNotesRow`:
       ```typescript
       export interface DbLectureNotesRow {
         id: string;
         lecture_id: string;
         user_id: string;
         summary: string;
         markdown: string;
         key_concepts: any[]; // JSONB array of KeyConcept
         exam_relevance: string | null;
         margin_notes: string | null;
         highlights: any[] | null; // JSONB array of NoteHighlight
         created_at: string;
         updated_at: string;
       }
       ```
    2. Implement `mapDbRowToStudyNotes(row: DbLectureNotesRow): StudyNotes`:
       Converts snake_case database row to camelCase `StudyNotes` interface, safely handling JSON parsing of `key_concepts` and `highlights`.
    3. Implement `fetchLectureNotes(lectureId: string): Promise<StudyNotes | null>`:
       - Checks if `supabase` client is available.
       - Queries `supabase.from('lecture_notes').select('*').eq('lecture_id', lectureId).maybeSingle()`.
       - If row found, returns `mapDbRowToStudyNotes(data)`.
       - If not found or error, returns `null` or logs error without crashing.
    4. Implement `saveLectureNotesToDb(lectureId: string, notes: StudyNotes, userId: string, marginNotes?: string, highlights?: NoteHighlight[]): Promise<StudyNotes>`:
       - Builds payload:
         ```typescript
         const payload = {
           lecture_id: lectureId,
           user_id: userId,
           summary: notes.summary || '',
           markdown: notes.markdown || '',
           key_concepts: notes.keyConcepts || [],
           exam_relevance: notes.examRelevance || null,
           margin_notes: marginNotes !== undefined ? marginNotes : (notes.marginNotes || ''),
           highlights: highlights || notes.highlights || [],
           updated_at: new Date().toISOString(),
         };
         ```
       - Uses `supabase.from('lecture_notes').upsert(payload, { onConflict: 'lecture_id' }).select().single()`.
       - Returns mapped `StudyNotes`.
    5. Update `fetchUserLectures()` to optionally join or hydrate notes from `lecture_notes` if convenient.
  </action>
  <acceptance_criteria>
    - `DbLectureNotesRow` defined matching the PostgreSQL schema
    - `fetchLectureNotes` retrieves and maps notes for a given lecture ID
    - `saveLectureNotesToDb` upserts notes record tied to `lecture_id` and authenticated `user_id`
    - Functions handle missing or unauthenticated sessions gracefully
  </acceptance_criteria>
